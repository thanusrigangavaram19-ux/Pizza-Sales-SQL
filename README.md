# 🍕 Pizza Sales Analysis Using SQL

## 📌 Project Overview

The Pizza Sales Analysis project focuses on analysing pizza sales data using SQL queries to understand sales performance, revenue generation, customer preferences, and ordering patterns.

The main objective of this project is to extract meaningful insights from sales data and understand how SQL can help businesses make data-driven decisions.

This project covers basic and intermediate SQL concepts, including filtering, grouping, sorting, joins, aggregate functions, and revenue analysis.

## 🎯 Project Objectives

- Calculate the total number of orders placed.
- Calculate the total revenue generated from pizza sales.
- Identify the highest-priced pizza.
- Identify the most frequently ordered pizza size.
- Find the top five most-ordered pizza types by quantity.
- Analyse the quantity of pizzas ordered by category.
- Understand the distribution of orders by hour of the day.
- Analyse category-wise pizza distribution.
- Calculate the average number of pizzas ordered per day.
- Identify the top three pizza types by revenue.
- Calculate each pizza type's percentage contribution to total revenue.
- Analyse cumulative revenue over time.

## 🗂️ Dataset and Tables

The project uses the following four tables:

### 1. Pizzas

### 2. Orders

## 📚 SQL Concepts Used

### Basic SQL
- `SELECT` — retrieves data from tables.
- `WHERE` — filters records based on conditions.
- `ORDER BY` — sorts query results.
- `GROUP BY` — groups records for aggregate calculations.

### Aggregate Functions
- `SUM()` — calculates total values.
- `COUNT()` — counts records.
- `AVG()` — calculates averages.
- `MAX()` — identifies the maximum value.

### Joins
- `JOIN` — combines related data from multiple tables.

### Advanced Analysis
- Subqueries for comparisons such as the second-highest salary-style maximum-value problem.
- Date-based grouping to analyse order trends.
- Revenue contribution calculations.
- Cumulative revenue analysis over time.
