# Pizza Sales Analysis Using SQL

## 1. Project Overview
This project explores pizza sales data using SQL to understand order patterns, product popularity, and revenue.

## 2. Project Objectives
- Calculate the total number of orders.
- Calculate total revenue from pizza sales.
- Identify the highest-priced pizza.
- Find the most common pizza size.
- Identify the top five pizza types by quantity ordered.
- Analyze pizza quantities by category.
- Examine order distribution by hour of the day.
- Calculate the average number of pizzas ordered per day.
- Identify the top three pizza types by revenue.
- Calculate each pizza type's percentage contribution to total revenue.
- Analyze cumulative revenue over time.

## 3. Tables Used
The project references these tables:
- `PIZZAS`
- `ORDERS`
- `ORDERS_DETAILS`
- `PIZZA_TYPES`

## 4. SQL Concepts Practiced
- `SELECT` — retrieve data
- `WHERE` — filter records
- `GROUP BY` — group records for analysis
- `ORDER BY` — sort results
- `JOIN` — combine related tables
- Aggregate functions — summarize data

## 5. Business Questions
The analysis is designed to answer questions about total orders, total revenue, pizza pricing, popular sizes and types, category-level quantities, hourly order patterns, daily order averages, revenue rankings, revenue contribution, and cumulative revenue.

## 6. Key Learning
This project provides practice in writing SQL queries, combining related tables, grouping data, and using aggregate functions to answer business questions.

## 7. Conclusion
SQL provides a practical way to explore pizza sales data and identify patterns in orders, product popularity, and revenue. These insights can support better-informed business decisions.
